# 数理の塔のモンスター画像

- ここに PNG（透過OK）を置き、`suri-data.js` の `images` に「ID: 'img/monsters/ファイル名.png'」を1行ずつ書くと表示されます。
- ID は `suri-data.js` の `monsters` のキー（slime、mob02、abs、dragon … guardian）。変身後は ID の後ろに 2（例：king2）。
- 登録していないモンスターは絵文字で表示されます（ゲームは止まりません）。
- 縦横比はそのまま、正方形の枠に収めて表示します（512×512 以上の正方形がおすすめ）。

## 第1章（1〜5階）のキャラクター画像（6枚）
`suri-data.js` の `characters` にある `image: null` を、ファイルの場所に書きかえるだけで切りかわります（`images` に書いてもOK）。

| ID | キャラクター | 階 |
|---|---|---|
| count_rabbit | カウント・ラビット | 1 |
| zero_slime | ゼロ・スライム（名前の解放まで「？？？」） | 2 |
| plus | プラス | 3 |
| minus | マイナス | 3 |
| abs_wolf | アブソリュート・ウルフ | 4 |
| nul | 零の番人ヌル | 5 |

- ふだんの会話では、顔のまわりを大きく表示します。顔の位置は `facePosition`（例 `'50% 28%'`＝横の真ん中・上から28%）、拡大率は `faceScale`（例 2.0）で調整します。
- ボスとの対面や試練の始まりでは、全身を表示します。
- 3階の戦闘の相手「プラスとマイナス」（twin_fox）は、2匹がいっしょの画像がなければ、plus と minus の画像を並べて表示します。
- 透過PNG・正方形・全身が入っているものがおすすめです（背景の透過はこちらでもできます）。
