# 会話の背景画像

ここに背景画像（16:9 がおすすめ。JPG / PNG / WebP）を置き、`suri-data.js` の `backgrounds` の `image: null` をファイルの場所に書きかえると切りかわります。
画像がないあいだは、CSS でえがいた仮の背景が出ます（エラーにはなりません）。

| ID | 背景 | 使う場面 |
|---|---|---|
| classroom | BG-P01 夕暮れの教室 | プロローグ シーン1 |
| tower | BG-P02 霧の中の数理の塔 | プロローグ シーン2・3 |
| street | 第1階 数字の消えた街道 | 第1章のはじまり・1階の会話 |

- `focus`：スマホ（縦長）で左右が切れるときに残す場所。例 `'50% 60%'`。
- `emblemAt`：塔の紋章が光る位置（tower だけ）。画像を入れたら、画像の中の紋章の位置に合わせてください。
- 教室の時計は、画像の上に小さな時計として重ねて表示します（止まる演出のため）。

## 縦長の画面（スマホ）での見え方
- 16:9 の画像は、スマホの縦画面では横幅のまんなか約3分の1だけが見えます（上下いっぱいに合わせて左右を切るため）。
- 人物・紋章・入口など大事なものは、画像の中央3分の1に入れてください。
- 端まで見せたい背景は `fit: 'contain'` にすると、縦画面では全体を縮めて表示し、上下のあきはぼかした同じ画像でうめます。
