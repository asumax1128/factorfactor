# Phase 2B：オンラインロビーの新UI接続

開始基準：Phase 2A `daa7440`。作業ブランチ `dev/next-major-20261015`。本番／main／Ver.5.25／Firebaseルールの変更なし。

## 実装範囲

- `src/next-lobby-ui.jsx`：承認済みネイビー＋青緑、共通Panel／ボタン／SVG。PCは2列と左ナビ、スマホは1列と既存5項目固定ナビ。
- `src/next-home-ui.jsx`：既存Frameにオンラインメニューだけを載せる。対戦／待機部屋へホームナビを持ち込まない。ホーム・ランキング総合の構成は維持。
- `index.html`：既存BattleHomeの操作・stateを表示コンポーネントに渡す。A／新B／Cのルーム作成ボタンは既存createRoomへ方式の初期値だけを渡す。汎用作成・大会の既存初期値はBのまま。ルームコード・参加・観戦・認証・退出は既存処理。
- すぐ対戦、既存ゴースト選択、CPU設定、週間ボス、フレンドレイド、全員検索、賞金首、レーティング画面、相手別成績、プロフィールへ接続。
- 現在レートは既存`CurrentRatings`と`useRatingHistoryProfile`を再利用し、E/N別にリアルタイム表示。旧`stats.rating`を新レートとして採用するロジックを追加しない。
- 一覧→他人の成績は既存の単一`win`状態を保持。賞金首一覧と成績モーダルの重なりを再発させない。
- 教師／限定開催は既存TeacherArea／StudentHostAreaをそのまま利用。新UIから権限付与・全件監視・ルール変更を追加しない。
- 設定が無効／確認中ならランダム対戦を利用不可にする。旧QMへ自動退行しない。CPU練習は利用可能。

## 未完了・後続作業

ロビーの表示と接続が対象。ゲーム・全サブ画面の新UI化完了とは扱わない。

- CPU・大会のBは現行の旧エンジンを維持し、CPUの選択肢は「B 従来ルール」と明記。新B2への切替は未実装。C共有エンジンを削除していない。
- フレンドレイド開催10公式戦条件と4難易度はPhase 2E。入口を移しただけで、この条件を実装済みとはしない。
- 自己ハイパー・TOP10選出・報酬除外は既存実装を維持。新たな選出条件は確定していない。
- ゴースト／ランキング／先生画面など、遷移先の専用画面は既存表示を利用。
- 本番・実SDK・実機Safari／Chromebook・全CIは未検証。開発ブランチpushで本番Actionsが起動しない設定を確認。

## 検証と画像

テストは既存`browser-harness.cjs`のローカル資産＋モックFirebase。ネットワークは置換し、本番を読み書きしない。ルーム作成等の書込みはモックデータ内だけ。

- `tests/next-lobby-browser.cjs`：375／390／430／1440px。実ReactでA/B/Cルーム作成、4桁入力検証、検索／賞金首→成績、プロフィール往復、ゴースト選択、CPUノーマルA開始、室内／戦闘でメニューナビが消えること、横はみ出しなしを検証。
- 設定無効時のランダム対戦停止／CPU利用可、教師権限の有無による先生メニュー表示を別シナリオで検証。モックの表示検証であり、実SDKの認可検証の代わりにはしない。
- 既存レーティング表示回帰は新プロフィールの「称号の装備・詳細記録」を経由する操作へ更新。保存値・丸め・履歴・順位の元のassertionは保持。
- 既存オンライン操作テストで入口ラベル変更によるTimeoutを発見。最終UIでは既存の「オンラインレーティング」「みんなの成績」の名称を保持し、無関係な既存テストを大量変更しない。

レーティング画面は既存`onRatedStats`を使用し、「オンラインへ戻る」でロビーへ戻る。ランキング総合から入った場合の戻り先は従来どおり総合画面。

最終の成功／失敗結果は[第2段階の状況](../PHASE2_STATUS.md)に記録する。
