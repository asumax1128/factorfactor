# 大会B2の追加実SDK検証

`tests/tournament-b2-emulator.cjs`を拡張し、既存の準決勝→決勝・同時解答・再送・自然時間終了引分けに加え、4選手のスイス予選2回戦→上位4名の準決勝→決勝（7試合）を確認した。

`tests/tournament-source-fixture.cjs`はindex.htmlの既存swissPair／swissStandings／matchOutcome／OMW等をそのまま抽出して実行する。テスト用に異なる順位式を作っていない。予選勝利3点、2回戦終了条件、既存シードからの決勝Tを通し、各回のB2結果を確認してから既存advanceトランザクションを進める。

- 2回戦後に教師を切断・復帰し、同じ結果と開始時刻を保持。
- 同じadvanceを同時再送しても回戦を二重に進めない。
- 第三者の回戦変更を拒否。
- 教師が選手本人の個人statsを書き換える操作も拒否。報酬確認は本人クライアントから既存recordを適用する。
- 決勝receipt・優勝処理の再試行後も1回だけ。通常レーティング・B戦績・通算戦績は不変。

今回のテスト追加に伴う大会本体・ルール・Firebaseルールの変更なし。多数人・奇数人数・全引分け等の全組合せや、学校ネットワーク・実機Safari／Chromebookを検証済みとはしない。
