# 第1.5段階：ランキング総合画面

基準：`2f903b0`、作業ブランチ`dev/next-major-20261015`。[第1段階](PHASE1_HANDOFF.md)の次の1作業のみを実装。main／本番Firebase／公開Ver.5.25は変更しない。

## 実装

- ホームのランキング、PCサイドバー、スマホ下部「順位」から総合画面へ移動。
- 入口はソロ／デイリー／レーティングの3つだけ。既存Bホームのシェルを再利用し、ランキング選択中の表示を追加。
- 各一覧→総合→ホームの戻るボタンを用意。PCサイドバー／スマホ5項目下部ナビを各一覧でも維持する。
- ホーム専用コンテンツは従来のまま。ランキング表示中は週間ボスの購読と週替わりタイマーを起動しない。
- 新画面の外枠・3入口はダークネイビー＋青緑。既存の一覧・表・タブは大規模に作り替えず再利用する。

|入口|既存実装への接続|変更しないもの|
|---|---|---|
|ソロ|`FactorHunt`に`rankingOnly`表示を追加。既存ランキング内容をモーダルからインライン枠へ表示|取得処理、ローカル／ネットランキング、集計・順位計算|
|デイリー|`DailyApp`／`DailyFactory.App`に`rankingsOnly`。今日／昨日・難易度選択・既存TOP10を表示|`daily-client.cjs`、`rankings(day,difficulty)`、保存パス、比較条件|
|レーティング|`BattleApp`の初期画面を`ratings`へ指定。既存config確認後に既存`OnlineRatedApp`のratingsビューへ|E/Nのレート参照・表示丸め・ランキング・順位計算・認証／設定の確認|

デイリーのランキング専用表示では挑戦・ミッションを表示せず、同コンポーネントによる優勝報酬の処理も起動しない。通常のデイリー画面は従来動作を維持する。デイリー設定を取得できない場合はエラーと総合へ戻るボタンを表示し、代わりに挑戦画面を開かない。

- ホーム→総合→既存3一覧→総合→ホーム。
- ソロの既存ランキングタブ、デイリー今日／昨日／難易度、レーティングE/Nの切替。

- 検証fixtureのレート・デイリー記録が保持され、挑戦・ランキング・週間ボスへの書き込みなし。
- 実React＋既存Firebaseモックでネットワークをローカルへ置換。本番には接続しない。既存のルート処理には認証・presence・日次報酬処理があるため、アプリ全体の全書き込みが0という意味ではない。

今回は既存の成功済み全体テストを再実行せず、ブラウザの上記限定テストとJS生成・差分確認だけ。全体ビルド・新規依存導入・大量撮影は実施していない。実機Safari／Chromebook・本番ランキングの突合・全CIは未実施。
