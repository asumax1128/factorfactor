# Phase 2D：ソロ／デイリーメニューの共通シェル

基準 `b01e282`。メニューとプレイ中のレイアウトを分離し、プレイ中・カウントダウン中にサイドバー／下部ナビを出さない。

- FactorHuntに任意renderMenuを追加。既存メニューDOM／難易度／開始関数／GAS再送／成績／ランキング／教師限定の数学の塔タイルを保持し、通常メニューだけ承認済みFrameで囲む。
- 旧ソロのロゴは表示だけ抑制し、共通シェルの正式PNGを表示。画像は加工・再生成・削除しない。
- DailyFactoryもメニュー／完了画面だけ共通Frameへ接続。挑戦中は従来BattleView。ランキング単独表示は既存のランキング総合シェルを継続し、二重に囲まない。
- 「今日のミッション」を「今日の挑戦」より上へ移動。H.Missions／受領処理・対象モード・JST日付・日次回数・ランキングは変更なし。
- `.next-home .next-legacy-menu`／`.next-legacy-daily`内だけ配色調整。旧ポップアップや内部のカードには一部従来デザインが残る。全ソロ戦闘・全デイリー画面の新UI完成とは扱わない。
