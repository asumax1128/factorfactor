# きせかえ：新UIの段階適用

- [スマホ390px](wardrobe-390.png)
- [PC1440px](wardrobe-1440.png)

新プロフィール・設定から開くきせかえだけをB改良版へ接続。所有判定、MASTER歴代到達判定、装備保存、タイル・背景・エフェクトの実際のプレビュー色は既存処理を使用。旧画面からのきせかえは従来表示を維持する。

375／390／430／1440pxで実操作を確認。body portalで親のtransformによる切り落としを避け、背景スクロール停止、Escape、Tabフォーカス循環、元のボタンへの復帰を追加。ロックした項目の取得条件を変えず、視認性を高めた。画像は実React＋モックデータのChromiumで取得・目視確認。実機Safari／Chromebookは未確認。

`tests/next-wardrobe-browser.cjs`は元のレート・戦績・EXP・称号が不変で、選択したskinフィールドのみが既存保存処理で更新されることを確認。`tests/master-effect-browser.cjs`は新プロフィールからの入口へ追従し、1820未満ロック／歴代MASTER解放／装備後の永久保持／実戦FX色を維持して検証した（旧ホームボタンを待つテスト入口の陳腐化を修正）。

共通UI全画面の完成ではない。ソロ内部、残りの対戦・結果詳細、教師専用画面等は未完了。
