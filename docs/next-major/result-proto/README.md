**独立した試作。実データ・`BattleResult`・Firebase・対戦処理には一切接続していません。** 数値・名前・称号はすべて架空です。ChatGPTディレクターのデザイン確認前に正式画面へ接続・統合しません。

開き方：`index.html` をブラウザで開く（上部のボタンでシナリオとPC／スマホを切替、`#s=a-win&v=phone`で直接指定）。画像は `screenshots/`（8シナリオ×PC1440／スマホ390）。

## 確認できるシナリオ
A勝利／A敗北／B勝利／B敗北（必須4種）＋ B引き分け／A4人（2位）／B3人（1位）／B履歴欠損・ゲスト。

## B. A方式とB方式の違い
共通：ヒーロー → あなたの成績 → 相手との比較 → ハイライト（最大3） → 成長 → 分析導線 → 次の行動。

|項目|A方式|B方式|
|---|---|---|
|主要タイル|得点／取った問題／最大コンボ／Perfect|得点／正解数／最大コンボ／Perfect|
|比較行|得点・取った問題・最大コンボ・Perfect・平均解答時間|＋誤答・時間切れ（全員分の確定履歴がある場合）|
|解答時間|**「獲得した問題のみの平均」**と明記（取れなかった問題の時間は記録がない）|正解した問題の平均（全員分あり）|
|方式固有|なし|「B方式の記録」：送信お邪魔カード／相殺／FREEZE使用／被ダメージ。送信は**「送った量」**で与ダメージではない旨を注記|
|ハイライト候補|逆転／勝敗を分けた問題／最速／コンボ|逆転／ピンチからの勝利／最大コンボ／最速／勝敗を分けた瞬間／同点に追いついた瞬間|
|分析|既存AResultDetails（得点推移・問題別）|既存BDetails（時間軸グラフ・攻撃相殺）|
画面内の表記は「B方式」に統一（「新B方式」は使わない）。

## C. 勝利・敗北・引き分けの演出方針
|結果|文字|背景|動き|
|---|---|---|---|
|勝利|`WIN!`（金 #f6bd62＋発光）|青緑の濃色グラデ|0.55秒のポップイン＋紙吹雪1.8秒（CSSのみ）＋数値カウントアップ0.8秒＋バー伸長|
|敗北|`LOSE…`（落ち着いた青灰）。赤は使わない|やや暗い青灰|0.8秒のフェードのみ。紙吹雪なし|
|引き分け|`DRAW`（空色 #83c8ff）|青系|0.6秒の左→右ワイプ|
- 複数人は順位を大きく（`2位`）、勝者以外は小さく`LOSE…`。
- **`prefers-reduced-motion`**：全アニメ・紙吹雪・バー伸長・カウントアップを無効化し最終状態を即表示。
- 効果音：試作では未実装。正式実装時は**既存のsound管理（ミュート／音量設定）経由のみ**で、勝利・敗北・引き分けの各1音を再生し、設定がミュートなら再生しない。操作を妨げる長い演出は置かない。

## D. 3人以上・データ欠損の表示方針
- **3人以上**：ヒーロー内に全員の順位・名前・得点の一覧（自分を強調）。比較バーは全員分を1行ずつ（自分が先頭、色は固定4色）。
- **全員分の値がない行は表示しない**（推測しない）。表示しない項目があるときは「記録がない項目は表示していません。」を1回だけ表示。
- **履歴欠損**：確認できる分析・ハイライトのみ出す（試作では「最大コンボ」1件）。グラフ・推移は出さず「詳細な得点履歴がない」と説明。Perfectなど未記録のタイルは「—／記録なし」。
- **ゲスト・練習**：経験値のみ。レート欄に既存の「名前と合言葉を登録すると…」案内。
- **ハイライト**：優先順位（逆転→ピンチ→勝敗を分けた→最大コンボ→最速）で並べ、同一の出来事（同じ問題番号／時刻）は重複除去、最大3件（`pickHighlights`、`rowVisible` が表示規則。正式実装でユニットテスト化）。
- 復習ボタン：間違いが0問なら無効表示。
