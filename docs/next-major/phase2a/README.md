# Phase 2A：共通基盤・プロフィール

## 実装

- `src/next-ui.jsx`：既存ホーム／ランキングのDOM配置を維持した`Frame`、`Panel`、`MetricGrid`、`Stat`、`BackButton`。画面タイトルへフォーカスを移す。
- `ui-next/tokens.css`：承認済みフォント・色・余白・角丸の共通トークン。`home.css`から読み込み、`.next-home`内だけに適用。数式・対戦・塔へ適用しない。
- `src/next-navigation.cjs`：主メニューの遷移名・選択中表示・プロフィールの戻り先。既存保存キーやhistory保存データは変更しない。
- `src/next-profile-ui.jsx`：実データ接続のプロフィール。概要／対戦記録／称号・装備の3タブ。ホーム、PCサイドバー、スマホメニュー、ソロの成績入口から開き、元のホーム／ランキング／ソロへ戻る。
- `src/profile-read.cjs`：純粋な表示モデル。文字列数値と実0を扱い、欠損・null・空文字・不正値は未記録。レート保存値や計算には丸めを戻さない。
- `index.html`：新プロフィールへの参照・遷移を接続。旧成績・称号装備・自己ゴースト・対戦相手別履歴は「称号の装備・詳細記録」から従来の`PlayerProfile`を開いて保持。きせかえも既存`Wardrobe`を利用。

プロフィール表示：名前／装備中称号／レベル・EXP／現在・歴代最高E/N／保存済み通算・最高連勝・Perfect等／A/B/C／ゴースト・BOT／週間ボス／確認可能な取得称号／装備。

## 保存元と重複防止

- `accounts/<本人>/stats`と`onlineSparkV1/profiles/<本人>`はホームと同じ取得を利用し、全ユーザー取得を追加しない。
- プロフィール表示中だけ`dailyV2/titles/<本人>`と当週`raidw/<週>/dmg/<本人>`を既存の取得方法で読む。退出時に解除。
- 旧stats通算、難易度別レーティング対戦、ゴースト／BOT記録を別枠に表示。同じ試合を含み得るため合算しない。
- B方式は既存`stats.B`を一度だけ表示。完全なw/l/dまたは保存gamesがなければ、欠損を0扱いして総数／勝率を作らない。
- 週参加・討伐貢献・最高ダメージは保存済み`stats.wk`、当週の個人ダメージ・出撃は本人ノード。出撃を完走回数と呼ばない。
- 旧取得判定、明示取得flag、日次称号flagから確認できる既得称号だけ表示。確定した100件マスターの名称へ読取対応付け。未取得の条件一覧、未承認の52件、隠し称号の未取得進捗は表示／適用しない。
- 未対応の旧装備IDを削除・強制解除しない。称号や装備の変更は従来の明示操作だけ。閲覧によるstats／profile書き込みは0。

新しい取得条件判定・移行・バックアップ書込・レート再計算は実装しない。既存rootの認証・presence・日次処理を含むアプリ全体が書込0という意味ではない。開発検証はネットワークをモックへ置換し、本番へ接続していない。
