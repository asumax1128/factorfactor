# AXIOMIA｜第5層「揺らぐ式の回廊」
<text color="secondary" size="sm">詳細脚本・第1稿｜第4層クリア直後〜第6層への旅立ち</text>

第5層の世界構成案について、**7項目すべてを正式承認・確定**とします。

これから制作するのは、AXIOMIA全10層の折り返し地点となる第5層の詳細脚本です。

第4層では「繰り返しの中にある余り」を学びました。第5層では、その繰り返しの中で生まれる変化を描きます。

今回の物語の中心にあるのは、次の問いです。

**「大切なものを守るために、変わらないことを選ぶ。それは本当に、大切なものを守ることになるのだろうか。」**

これまでより少し切なく、それでいて最後には希望を感じられる物語を目指します。
