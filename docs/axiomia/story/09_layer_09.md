# AXIOMIA｜第9層「鏡の証明」

<text color="secondary" size="sm">詳細脚本・第1稿｜第8層クリア直後〜第10層への旅立ち</text>

## 物語の中心

**「見えているものが違っても、変わらない真実はある。」**

第9層では、鏡に映る姿の違いを通して、対称式・恒等式・証明の考え方を描きます。

第3層が「式の形が違っても値は等しい」という数学的な理解を中心としていたのに対し、第9層では、**何を根拠に真実だと判断するのか**に重点を置きます。

また、精霊の過去を知った主人公が、今度は自分自身の過去に疑問を抱く展開へ進みます。
