# AXIOMIA｜第8層「双式の観測室」

<text color="secondary" size="sm">詳細脚本・第1稿｜第7層クリア直後〜第9層への旅立ち</text>

## 第8層の物語の核心

**「一つだけを見ていては、見つけられない答えがある。」**

この層では、二つの観測記録を照らし合わせる冒険を通して、主人公がコーデックスの声の過去にたどり着きます。

前半は、星空を舞台にした幻想的な冒険。

中盤は、失われた記録を追うミステリー。

終盤は、連立パペットとの対決と、精霊の正体が明らかになる感情的な場面です。
