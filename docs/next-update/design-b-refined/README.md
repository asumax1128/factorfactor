抽象的なキャッチコピーは追加していない。操作アイコンは同じSVG線画セット。先生向け機能は一般プレイヤーの見本へ表示せず、実装時も既存権限を維持する。

## 仮ロゴの実装境界

- ロゴ参照：`../design-directions/title-original.png`。元HTMLから取り出した同一PNGであり、再描画・再圧縮・色変更なし。
- 画像の背景は透明。白い背景板を置かず、元の黒い輪郭が暗い画面に馴染みにくい点も含めて仮ロゴとして扱う。
- 共通コンポーネントの差し替え口に相当するbrand-config.jsonを、PCとスマホの両配置へ適用するレビュー実装。
- 新ロゴのデザイン、配色、比率は所有者が決めるまで確定しない。

## フォント・ライセンス・転送量

レビュー用のローカルWOFF：heading 32,676 bytes、body 33,252 bytes、number 11,452 bytes、合計77,380 bytes。Zen Kaku Gothic NewとRajdhaniのSIL OFL 1.1本文をfontsへ同梱。公式Google Fonts配布を固定文言用にサブセット化し、変更したfont familyはBHeading/BBody/BNumberへ変更。元TTFとWOFFのSHA-256はfonts/manifest.json。

実フォントを読み込んだ状態で撮影。外部CDNへ接続せず、数式KaTeXには一切適用していない。これはレビュー文言専用のサブセットなので、未知の日本語を含む本番へそのまま移植しない。方向性確認後に全体の文字範囲・分割WOFF2・キャッシュを設計し、実機で測る。

## 確認結果

`node docs/next-update/design-b-refined/capture.cjs`：4画面成功。

- 3書体の読み込み、元ロゴdecode・透明背景、各画面の選択中ナビを確認。
- ホームのボス描画を確認（表示領域の高さ240px以上、幅260px以上）。
- PCのhover反応、スマホのメニューシート開閉/Escape/aria-expandedを確認。
- 320/390/768/900/1024/1366/1440pxの横overflowなし。
- JSエラー・外部ネットワークリクエストなし。本番Firebase接続なし。
- reduced-motionのCSSを用意。OS設定・Safari/ChromeOS/Windows実機での体感、音声、実ゲーム進行は未確認。

checks.jsonに実行結果。依存の追加インストール/ゲームテストの再実行はしていない。修正はレビュー資料のみなので、既存ゲームの回帰テスト成功を今回の結果として主張しない。

## 再現・引継ぎ

- HTML生成：`python3 docs/next-update/design-b-refined/build_review.py`。共通nav/アイコン/本人情報からhome.htmlとonline.htmlを生成。
- 撮影：`node docs/next-update/design-b-refined/capture.cjs`。必要ならCHROMIUM_PATHを指定。
- `refined.css`がこのレビュー専用のスタイル。実ゲームのCSS/src/indexへは未接続。
- 新しい文字を加えた場合はfontサブセットも更新して欠損を確認する。
- 次の承認範囲は「改良したホームとロビーを基準に実装へ進めるか」。これを本番公開・main統合・データ移行の許可とは扱わない。
