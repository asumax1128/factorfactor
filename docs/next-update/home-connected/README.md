# 承認済みBホームの実アプリ接続・週間ボスHP

基準：`281fe70`のB改良版／スマホバランス型。所有者がホームレビュー完了・開発ブランチの実アプリ接続を承認した。main統合・本番公開・本番データ変更は引き続き禁止。版番号はVer.5.25のまま。

## 実装範囲

- ログイン後の入口を新ホームに変更。PC左サイドバー、スマホ5項目固定ナビ、実プロフィール・現在レーティングを接続。
- オンライン対戦→既存`BattleApp`、ソロ→既存`FactorHunt`の難易度選択、デイリー→既存`DailyApp`、ボス→既存`WeeklyRaidApp`、学びの部屋→既存`LearnApp`。
- ランキング／あそびかた→既存ソロメニューのランキングモーダル／チュートリアルへ直接表示。ランキング総合メニューの新設・説明の全面更新は今回未実装。
- 成績確認→既存`PlayerProfile`、設定→音声・きせかえ・ログアウト。PCにも設定入口を配置。
- 新ホームから離れると専用CSS・週間ボス購読・週替わりチェックを解除。数学・得点・同期・保存計算は変更しない。
- 従来のソロメニューへ「ホームへ」を追加。オンライン・デイリー・ボス等の既存終了コールバックは新ホームへ戻る。
- ログインボーナスは従来のコンポーネントを維持。アプリ既存の認証・presence・報酬処理を削除／再実装していない。
- 新UIモジュールの読み込み失敗時は、エラー表示と従来のソロメニューへフォールバックする。

新ロビーの全面デザイン、全バトル／リザルトの統一、100称号等の大型更新全体の完成を意味しない。

## HPの一次資料と取得元

`index.html`の検索語`weeklyInfo`／`WEEKLY_HP`／`WeeklyRaidApp`／`ensureWeekMeta`／`bossForm`を参照。行番号は更新で変わるため関数名で追跡する。

|要素|実装・保存元|
|---|---|
|最大HP|`WEEKLY_HP=30000` × ボス特性`hpK` × `WK_RAGE_HP^rage`を`Math.round`。現行`weeklyInfo`をそのまま呼ぶ|
|ボス・怒り状態|`games/factor/raidw/<JST月曜の日付>/meta`の`boss`, `rage`|
|現在HP|同週`dmg/<account>/d`の合計を最大HPから減算。既存の復活特性があれば既存式の回復分を加算|
|ダメージ反映|既存`WeeklyRaidApp`が正解等で各プレイヤーの`dmg`をトランザクション更新。ホームは`value`通知で再計算|
|同時攻撃|既存プレイヤー別トランザクションを維持。ホームでは加算や書き込みをしない|
|討伐|`weeklyInfo.dead`／`hp<=0`。表示は0に下限を制限し「討伐済み」。既存`kill`の確定・報酬処理は変更しない|
|復活後の画像／名称|既存`bossForm(info.boss, info.revived)`|
|週替わり|`weekKey(fbNow())`を1秒ごとに確認。JST月曜のキー変更で旧週購読解除・新週へ切替。ダメージ削除・リセット書き込みなし|
|新しい週の初期化|既存レイド画面の`ensureWeekMeta`に任せる。ホームは初期化せず、meta未確定なら「次のボスを準備中」|

HPの数値・最大HP・ダメージ・怒り・復活の仕様を変更していない。過去依頼のHP3倍化を、この表示追加に混ぜて実施していない。

### 読み込み・異常系

metaとdmgの**両方の初回通知**を待つ。読み込み中は満タンHPを仮表示しない。metaがなければ準備中。認証初期化中は読み込み、認証エラーは取得失敗、権限キャンセルは権限不足として表示する。失敗時は架空HPを表示せず再試行できる。週・購読世代が古いコールバックは無視する。

数値は既存計算値、ゲージの長さは0〜100%に制限。色だけに依存せず数値・割合・討伐状態を併記する。

## 読み書き・データ保護

ホーム独自のHP購読は当週`meta`と`dmg`の2本。前週全件・全ユーザー・sup・履歴は追加取得しない。本人statsと本人オンラインプロフィールは既存取得方式を利用。HP表示のためのset/update/transactionは**0**。画面を離れれば購読解除。ゲーム中にホームのタイマーや購読を残さない。

既存のアプリ全体の認証・presence・ログインボーナス等は従来どおりであり、ホームを含むアプリ全体が一切書き込まないという意味ではない。今回の動作検証は全通信をローカルへ置換し、本番Firebaseを読み書きしていない。ルール・データ構造・アカウント・称号・装備・EXP・レート・戦績の移行は行っていない。

## 新ロゴの状態：差し替え保留

[受領画像・無加工JPEG](logo-received.jpg)を参照。背景付きJPEGでありアルファチャンネルがない。下段は反転したような文字形状で、「FACTOR」のC・Tを含む綴りを正常と確認できない。これを透過PNGへ拡張子だけ変えたり、別ロゴを生成したりしていない。

正式仕様を満たす**正確な「FACTOR × FACTOR」の背景透過PNG**の受領待ち。現在は承認済みレビューの仮ロゴを維持し「仮ロゴ」と明記。元画像を削除せず`ui-next/logo-placeholder.png`として使用。元の縦横比・透過を保持。正式画像受領後は専用ロゴのsrcを差し替えるだけで済む構造。小さいサイズ・高DPIでの新ロゴの可読性は未検証。
