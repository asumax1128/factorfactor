# 旧UI方向性レビュー — 不採用

**所有者により不採用。以下は経緯保存用であり、実装対象ではありません。** B案の方向性が選択済み。最新版は[B案改良版4画面](design-b-refined/README.md)を参照してください。

**これは静的提案。実アプリの新メニュー/リザルトはまだ実装していない。** 数値・報酬は全て例示であり、本番データを取得していない。

- 背景paper #F5F2EC、白card、orange #E4572E、既存の丸い太字日本語を継続。数式は既存fontのまま。
- ホームは本人情報の下に「オンライン」「ソロホーム」「デイリー」「ランキング」「あそびかた」の5導線。本人情報から成績/きせかえ/自己ゴーストへ入る。
- オンラインは「すぐ遊ぶ」を主操作にし、「友だちと対戦」「協力」「練習/ゴースト」「記録/ライバル」の目的別カードへ整理。先生専用開催/分析は権限付きカードを追加する設計。
- 結果は確定状態→双方スコア→個人成績→グラフ→確定報酬→次の操作。A詳細の情報を落とさず、Bは確定時系列、Cは別々の貢献指標を載せる。
- スマホは1〜2列、PCは余白を確保。タッチ領域44px以上。色だけに依存せず凡例/数値/見出しを使う。
- 塔RPG/ボス固有演出は保持。隠し称号の演出は100件仕様受領後に独立したレビューを作る。
- prototypeは外部フォントをダウンロードせず、既存端末フォールバックを使う。実Webフォントの美観は実装時に別確認する。
