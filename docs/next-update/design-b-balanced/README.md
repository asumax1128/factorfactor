## 変更点と維持した部分

- スマホのボスカードは**374.9 → 308.6px（−66.3px、−17.7%）**。画像領域は248 → 218px（−12.1%）に留め、見出しの上下余白とフッターを整理した。
- ボス名と「ボスに挑む」を同じ行へまとめ、重複する「協力レイド」の小見出しをスマホだけ省略。今週のボスという見出しは維持。
- 元のドラゴン画像をそのまま使用。`object-fit:contain`で全身を収め、縦横比を維持。画像の加工・引き伸ばし・切り抜きは行っていない。
- ロゴ・設定 → ホーム → プレイヤー → 対戦／ソロの2列 → ボス → デイリー → ランキング／あそびかた、という順序を維持。
- 仮ロゴ・配色・フォント・アイコン・主要モードカード・プロフィール・5項目の固定ナビは継承。オンラインロビーも変更なし。
- PCには追加CSSを適用しない。1440×1080の変更前後スクリーンショットは**PNGバイト列まで一致**。左サイドバー、ボス画像320px、カード高さ467.4pxを維持。

### 操作性・文字・下部ナビ

- 「ボスに挑む」は**幅109.0×高さ45.6px**を維持。文字サイズ11pxも維持し、主要モード・プレイヤー情報の字を縮めていない。スマホ実機の読みやすさは最終レビュー対象。
- 375／390／430pxで主要モードは2列を保持。横スクロールなし。
- iPhone用に`viewport-fit=cover`を追加。ナビ既存の`env(safe-area-inset-bottom)`に加えて、コンテンツ末尾の余白にも同じセーフエリアを加算。
- 通常表示のナビ高さ68pxに対してページ下余白105pxを確保。**34pxのセーフエリアをCSSで模擬**した状態でも、ボス・デイリー・ランキング・あそびかたへスクロールし、中心座標がナビに遮られず操作対象へ届くことを確認した。
- 固定ナビはスクロール途中の下端にある内容へ重なることはあるが、末尾までスクロールすればボタンをナビ上へ出せる。全ボタンが初期表示内に収まるという意味ではない。
- 下部メニューの開閉・Escapeで閉じる動作を3幅で確認。
- ドラゴン／クラーケン等、既存アセット5種類×3幅でカード高さが変わらず、画像はcontain表示。これだけで全ボスの名前の長さや全イラストの見え方を保証するものではない。

## 成長・競争情報の表示案（今回の画像へ追加していない）

プレイヤーカードを過密にせず、現在のイージー／ノーマルの数値を維持する。ランク名と次ランクの閾値を小さな1行へ追加する案を推奨する。対象難易度を必ず併記し、最高レートと混同しない。

根拠：`index.html:7756`の`RANKS`、`rankOf`。シルバー1530／ゴールド1580／プラチナ1650／ダイヤモンド1730／マスター1820。例示の現在値1666なら「イージー：プラチナ・次は1730」。閾値そのものを表示すると、内部小数値と丸めた表示値の差による誤解を抑えられる。「あと○」を使う場合は未丸めの内部値との差を使い、必要整数値を切り上げる（1665.6ならあと65）。内部判定は変更しない。

現在順位は、対象難易度の既存キャッシュに本人の正しい順位がある場合だけ表示する案。TOP10圏外などで順位が分からない場合に順位を推測しない。このレビューのためのランキング全件取得や監視は追加していない。難易度切替・競争情報の実装は別途レビューする。
