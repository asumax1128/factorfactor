# 数学の塔 第1章：Windows＋iPhone ローカル試遊

このパッケージには未公開原稿・画像が含まれます。非公開保管を維持し、公開Webサーバー、GitHub Pages、公開トンネル、ルーターのポート転送では配信しないでください。

## Windows PCで起動

1. ZIPをPCへ保存し、必ず「すべて展開」する。ZIP内部のまま起動しない。
2. Python 3.10以上が必要。未導入なら https://www.python.org/downloads/windows/ から導入する。追加料金は不要。インストール時にPython Launcher/「Add Python to PATH」を有効にする。
3. 展開フォルダの `start-windows.bat` をダブルクリックする。黒い起動画面を閉じずに残す。
4. PCブラウザ（Edge/Chrome）で `http://127.0.0.1:8765` を開く。
5. 黒い画面に出る「入室コード」を入力する。本番の先生パスワードではない。
6. モック先生として塔の画面へ自動で入る。NORMALを選び「冒険を続ける」→「試練を開始」。会話はタップ/クリックで進める。
7. 戦闘は1枚を押したまま2枚目へ線を引き、指/マウスを離す。2枚を別々にタップする操作ではない。

起動しない場合はフォルダでターミナルを開き `py -3 start.py --lan` を実行するとエラーを確認できます。PCだけなら `py -3 start.py` でLANへ配信せず起動できます。終了は黒い画面でCtrl+C。

## iPhone（Safari）

1. PCとiPhoneを同じ信頼できるWi-Fiへ接続する。PCは起動したままにする。
2. Windowsのコマンドプロンプトで `ipconfig` を実行し、「Wireless LAN adapter Wi-Fi」のIPv4アドレスを確認する。例：192.168.1.20。
3. Safariで `http://192.168.1.20:8765` のように、実際のPCアドレスを開く。iPhoneで127.0.0.1を使わない。
4. PCに表示された同じ入室コードを入力する。縦向きで操作する。
5. Windowsファイアウォールで許可が必要なら、信頼できるプライベートネットワークのみでPythonを許可する。パブリックネットワークには許可しない。

到達できない場合：PCのIP、サーバー起動、同じWi-Fi、ファイアウォール、ルーターの端末間通信制限を確認する。公衆Wi-FiやゲストWi-Fiは使わない。HTTPのためLAN内通信は暗号化されない。入室コードはインターネットの先生認証の代替ではなく、手元の試遊ファイルをLANで配る際の保護です。外部公開にはHTTPSと別のサーバー側認証設計・ユーザー承認が必要。

## 保存・認証・費用

本番Firebase SDKは含めず、Firebase APIのテストダブルと架空の先生/UID/accountKey/grantを使用。実アカウントの先生権限は検証しない。原稿/画像/JSを含む全ゲームファイルは入室コードによるサーバーログイン後だけ取得可能。コードは起動のたびに新しくなる。

保存先は各ブラウザのlocalStorage（math-tower-local-v1名前空間）。サーバーやFirebaseへセーブしない。PCとiPhoneの進行は独立で、同期/再ログイン時の端末引継ぎはない。同じURL・ブラウザで再読み込みすると進行を復元する。ブラウザデータ削除/プライベートブラウズ/PCのIP変更で保存が失われたり別保存になる可能性がある。戦闘盤面の途中復元は行わず最後の保存状態から再試行する。

サービス利用料・新サービス・本番ルール変更は不要。通信は同一PC/LANのみ。スクリーンショット用モック認可やこの入室コードを本番Firebase認可の検証結果と混同しない。

## 試遊チェックリスト

- [ ] 初回プロローグ→章導入→第1階（未読は最後まで進める）
- [ ] NORMALで第1〜5階完走→章末→第2章へ進めない
- [ ] EASY/HARD切替（難易度ごとの進行は別）
- [ ] 誤答：通常HP−5／ヌルHP−10、同Lv別問題
- [ ] 時間切れ：45秒、HP−10、同じ問題でタイマー再開
- [ ] ポーズ中停止→再開（同程度の別問題、HP/コンボ維持）
- [ ] HP0で敗北→再挑戦→章HP100で第1階へ
- [ ] HARD：敵HP0でもLv8以上の正解が必要な表示
- [ ] 会話、既読スキップ、図鑑、数理の書、学習記録
- [ ] ホームまで戻り保存→ページ再読み込み
- [ ] PCマウス、iPhone縦画面・指のドラッグ、式/タイルの可読性

## 試遊できない機能

本番の先生認証・Firebase保存/端末同期、オンライン対戦、ランキング、公式学習記録/称号、未実装の零の試練、後続章は対象外。章1の取得済みソースを先生から秘匿する機能はない。音/Safari実機はユーザーによる確認が必要。
