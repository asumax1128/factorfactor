# 非公開資料の保全とレビュー

## 現在の保全と外部バックアップ

Codexの `/workspace/handoff-preservation/` は作業環境内の保全であり、環境外の永続バックアップではない。旧devは削除せず読み取り専用で保持する。

用意済みの旧dev Git bundleには原稿・設定・配信用24画像・原本24画像と履歴が含まれる。今回、一時ディレクトリへ復元し、HEADと48画像のSHA-256一致を確認した。正式版の作業ブランチもGit bundleで取り出せる。認証情報・環境変数・node_modulesを含めない。

推奨する保存方法：

1. ユーザーのPCへGit bundle、画像チェックサム台帳、非公開パッケージ、仕様書、レビューZIPを保存する。
2. PCの7-Zip等でAES-256・ファイル名暗号化を有効にして暗号化する。パスワードはローカルで入力し、チャットや公開repoへ書かない。復旧情報はアーカイブと別に管理する。
3. 暗号化済みアーカイブを外付け媒体、または既に利用している本人専用の非公開ストレージにも保存する。公開リンク・「リンクを知る全員」共有を使わず、レビュー担当者のみを指定する。
4. コピー後にSHA-256を確認し、一度解凍・復元して原稿と画像を読めることを確認する。
5. Claudeの資料アクセスと、正式版から旧dev/Cloudflareへの依存がなくなったことを確認してから、削除・切り離しを別途判断する。

例：Windowsでは `Get-FileHash -Algorithm SHA256 ファイル名`、macOS/Linuxでは `shasum -a 256 ファイル名` で比較できる。Git bundleは `git clone /保管先/history.bundle /復元先` で復元する。確認した旧devのHEADは `0dd2f14b5081bb6acd831003026706d653e8f5ab`。

今回、環境外へのアップロード・新サービス契約・課金は行っていない。外部保存が済んだとは報告しない。
